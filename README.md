# Campus Link — Student App

A cross-platform student application developed with Flutter and Dart as part of the Campus Link ecosystem. The project integrates Firebase services and provides a foundation for student-facing tools across mobile and desktop platforms.

## Tech Stack

- **Flutter & Dart** — Cross-platform application development
- **Firebase Authentication** — Authentication services
- **Cloud Firestore** — Cloud data management
- **Firebase Storage** — File storage
- **Firebase Cloud Messaging** — Push notifications
- **Provider & RxDart** — State management and reactive programming
- **Table Calendar** — Calendar components

## Getting Started

### Prerequisites
- Flutter SDK
- Dart SDK (3.5.3 or compatible)
- Firebase project configuration

### Installation

```bash
git clone https://github.com/Theproxycos/student_app.git
cd student_app
flutter pub get
flutter run
```

Configure the required Firebase services and platform-specific settings before running the application.

## Project Structure

- `lib/` — Application source code
- `assets/` — Images and application assets
- `android/` — Android platform configuration
- `ios/` — iOS platform configuration
- `web/` — Web platform configuration
- `windows/`, `linux/`, `macos/` — Desktop platform configuration

## Security Notice

Some files have been intentionally removed from this repository. Sensitive credentials and service-account keys should never be bundled with a client application or committed to a public repository.
